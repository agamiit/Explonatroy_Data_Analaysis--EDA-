# Explonatory_Data_Analaysis--EDA-
🎇 Diwali Sales Analysis
This project analyzes a Diwali sales dataset to uncover customer behavior, purchasing patterns, and sales insights. The main objective is to perform Exploratory Data Analysis (EDA) and generate useful business insights.

📌 Project Overview
Conducted data cleaning and preprocessing.
Performed EDA using Python libraries.
Visualized customer demographics, purchase behavior, and product categories.
Derived insights to help improve customer targeting and marketing strategies.

🛠️ Technologies & Libraries Used
Python
Pandas – Data manipulation & cleaning
NumPy – Numerical operations
Matplotlib – Data visualization
Seaborn – Advanced visualizations & statistical plots

📊 Key Analysis Performed
Customer demographics (Age, Gender, Marital Status, State)
Purchasing power and spending habits
Product category-wise sales analysis
Insights for better business decision-making
